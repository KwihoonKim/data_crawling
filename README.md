ASOS Weather Data Crawler (Korea Meteorological Administration)

<1.Overview>
====================================================================================
This repository provides a Python-based crawler for downloading weather observation data 
from the ASOS (Automated Synoptic Observing System) operated by the 
Korea Meteorological Administration (KMA).

The script allows users to automatically collect historical meteorological data 
(e.g., precipitation, temperature, wind speed, humidity) for selected stations 
and periods.

====================================================================================

<2.Features>
====================================================================================
- Download ASOS station data for user-defined periods
- Select specific meteorological variables
- Automatic handling of request parameters
- Save output as CSV format
- Simple and reproducible workflow
====================================================================================

<3.Data Source>
====================================================================================
Data are collected from:

Korea Meteorological Administration (KMA)  
ASOS Data Portal: https://data.kma.go.kr

Users must comply with the KMA data usage policy.

====================================================================================
